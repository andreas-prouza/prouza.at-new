### General overview of current technologies

* Performance analysis and optimization
* Monitoring
* SQL functions
* SQL procedures
* RPG/CL programs from SQL calls
* Versioning of tables
* Journalization
* Commitment Control
* Index strategies and types
* MQT
* Debugging SQL procedures and functions
* Hierarchical queries
* SQL Injection (Security)
* Creating tables with new features (e.g. automatic filling of system and job information)
* Grouping
* Unicode
* Row and Column Access Control (RCAC)
* WebServices via SQL calls
* Run JDBC jobs in a separate subsystem
* Exception handling


### Advanced

Here the topics mentioned above are dealt with in greater depth.  
Theories are reinforced through practical exercises.

The goal is ...  
* encounter everyday problems through exercises, which are identified and solved in the workshop
* present best practice solutions
* to gain a better understanding of how DB works through experimentation and exploration
* see the benefits of these features in everyday life
* recognize where there are limitations
* and at the end everyone will have a collection of practical examples to fall back on in the future
