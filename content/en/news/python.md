## Installation via `yum`
Über `yum` kann die aktuelle Version von Python installiert werden:
```sh
yum install python39
```

## DB2 Verbindung
Hier gibt es 2 Möglichkeiten:
* via ODBC
* via IBM eigenen DB2 Connector

## Vielzahl an Einsatzmöglichkeiten
* Excel generieren
* PDF generieren
* WebService Server/Client
* Web Applikationen
* Socket Server/Client
* Source Analysen und Auswertungen
* uvm.
