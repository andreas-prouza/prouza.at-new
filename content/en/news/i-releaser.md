Automated deployment tool [i-releaser](https://github.com/andreas-prouza/i-releaser).

* Workflow based
* Individual workflows configurable
* Parallelization of processes

Details can be found on GitHub: https://github.com/andreas-prouza/i-releaser

### Actions

* There are predefined actions (build, save, transfer, backup, etc.).
However, additional individual actions can also be defined (mail dispatch, JIRA API call, additional checks, ...)
* Each task contains its own log / job log
