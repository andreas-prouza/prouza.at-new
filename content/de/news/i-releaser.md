Automatisiertes Deployment Tool [i-releaser](https://github.com/andreas-prouza/i-releaser).

* Workflow basierend
* Individuelle Workflows konfigurierbar
* Paralellisierung von Prozesse

Details findet ihr auf GitHub: https://github.com/andreas-prouza/i-releaser

### Aktionen

* Es gibt vordefinierte Aktionen (build, save, transfer, backup, usw.).
Es können aber auch noch zusätzlich individuelle Aktionen definiert werden (Mail Versand, JIRA API Aufruf, zusätzliche Checks, ...)
* Jeder Task enthält sein eigenes Log / Joblog
